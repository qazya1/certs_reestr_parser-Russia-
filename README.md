# Парсер реестра сертификатов и деклараций ФСА (Росаккредитация)

Настольное приложение на Python с графическим интерфейсом (Tkinter) для массовой выгрузки данных из открытого реестра сертификатов соответствия и деклараций Федеральной службы по аккредитации (ФСА, [pub.fsa.gov.ru](https://pub.fsa.gov.ru)) — государственного портала, где публикуются сведения обо всех сертифицированных в России и ЕАЭС товарах.

Инструмент избавляет от рутинного ручного поиска по сайту реестра: пользователь задаёт нужные фильтры в удобном окне, а приложение само проходит по всем страницам результатов, дособирает по каждому сертификату контактные данные заявителя (телефон, e-mail, ФИО) и выгружает итоговую таблицу в Excel.

## Возможности

- **Фильтрация по множеству параметров реестра**, полностью повторяющих фильтры официального сайта:
  - статус сертификата (действует, приостановлен, прекращён, архивный и т.д.);
  - тип сертификата (ТР ТС/ЕАЭС, ТР РФ, Единый перечень ЕАЭС/РФ);
  - тип объекта сертификации (единичное изделие, партия, серийный выпуск);
  - происхождение продукции;
  - группа продукции ЕАЭС / РФ — по иерархическому дереву товарных групп (аналог ТН ВЭД/ОКПД2);
  - позиция в едином перечне продукции ЕАЭС / РФ, подлежащей обязательной сертификации;
  - применяемый технический регламент (ТР ТС/ЕАЭС, ГОСТ, федеральные законы);
  - вид заявителя (изготовитель, продавец, поставщик, уполномоченное лицо и др.);
  - диапазон даты регистрации и даты окончания действия сертификата.
- **Древовидные меню** для громоздких многоуровневых справочников (группы продукции, единые перечни), построенные рекурсивным разбором JSON произвольной вложенности.
- **Автоматическая авторизация** на портале ФСА (анонимная сессия) и обход постраничной пагинации API реестра до полного исчерпания результатов.
- **Дообогащение данных**: для каждого найденного сертификата приложение делает дополнительный запрос к API, чтобы вытащить контакты заявителя — телефон, e-mail, ФИО (для физлиц/ИП).
- **Устойчивость к сбоям сети**: повторные попытки запроса при обрыве соединения или ошибке сервера, случайные паузы между запросами, чтобы не перегружать и не блокироваться государственным API.
- **Экспорт результата** в файл `result.xlsx` со столбцами:
  - ссылка на карточку сертификата в реестре;
  - дата окончания действия;
  - заявитель и изготовитель;
  - общее наименование продукции;
  - телефон и e-mail заявителя;
  - номер (id) сертификата;
  - имя физического лица (если применимо).

## Как это устроено

1. **Справочники фильтров** хранятся в отдельных JSON-файлах и один в один соответствуют спискам фильтрации на сайте `pub.fsa.gov.ru`:
   - `status.json` — статусы сертификатов;
   - `idCertType.json` — типы сертификатов;
   - `idCertObjectType.json` — типы объектов сертификации;
   - `idProductType.json` — происхождение продукции;
   - `idApplicantType.json` — виды заявителей;
   - `idTechReg.json` — технические регламенты;
   - `idGroupEEU.json` / `idGroupRU.json` — товарные группы ЕАЭС и РФ (древовидная структура);
   - `idProductSingleListEEU.json` / `idProductSingleListRU.json` — единые перечни продукции ЕАЭС и РФ (древовидная структура).
2. **GUI (Tkinter)** динамически строит выпадающие меню и чекбоксы по каждому справочнику; выбор пользователя накапливается в общем JSON-фильтре, который затем один в один отправляется в REST API реестра.
3. **По нажатию кнопки «Запустить»**:
   - выполняется анонимный вход в API ФСА и получение bearer-токена;
   - приложение постранично запрашивает `POST /api/v1/rss/common/certificates/get` с собранным фильтром;
   - по каждому сертификату из списка результатов дополнительно дергается `GET /api/v1/rss/common/certificates/{id}` за карточкой заявителя;
   - все строки собираются в `pandas.DataFrame` и сохраняются в `result.xlsx` через `xlsxwriter`.

## Стек технологий

- **Python 3**
- **Tkinter** — графический интерфейс
- **requests** — работа с REST API реестра ФСА
- **pandas + xlsxwriter** — формирование и экспорт Excel-отчёта
- **python-dateutil** — работа с датами

## Установка и запуск

```bash
pip install requests pandas xlsxwriter python-dateutil
python main.py
```

После запуска откроется окно с фильтрами. Даты вводятся в формате `год-месяц-число` (например, `2024-01-31`). После настройки фильтров нажмите **«Запустить»** — приложение свернёт окно и начнёт выгрузку; по завершении в папке проекта появится файл `result.xlsx` со всеми найденными сертификатами.

> Если ни один фильтр не задан, приложение выгрузит весь реестр целиком — это может занять продолжительное время, так как база данных содержит сотни тысяч записей, а к каждому сертификату выполняется отдельный запрос.

## Область применения

Проект полезен специалистам по сертификации, комплаенсу, логистике и закупкам, которым нужно быстро получить структурированную выборку из реестра ФСА (например, все действующие сертификаты по конкретному техрегламенту или товарной группе) без ручного постраничного просмотра сайта и без доступа к платным агрегаторам данных.
